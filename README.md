# Thin Market Monitor

Windows-приложение для фильтрации спотовых рынков, мониторинга импульсов цены и объёма и просмотра минутных свечей. [Скачать Windows x64 EXE](https://github.com/ksen0v/thin-market-monitor/releases/latest/download/ThinMarketMonitor-win-x64.exe). Запустите файл из папки, доступной на запись. Приложение сохраняет настройки в `%LOCALAPPDATA%\ThinMarketMonitor\settings.json`.

## Фильтр и выбор рынка

- ✓ — активный листинг обязателен. Несколько ✓ дают пересечение.
- × — активного листинга быть не должно. Любая из бирж с × исключает совпадение.
- — — биржа игнорируется при сравнении. При наличии ✓ она не участвует и в выборе рынка. Если ✓ нет, исходный список — объединение доступных каталогов бирж без отметок. Пустой фильтр даёт такое же объединение.
- Нажатие на логотип биржи переключает состояния —, ✓ и ×. Результат пересчитывается сразу, а каталоги обновляются автоматически при запуске и каждые пять минут. При ошибке любого каталога с ✓ или × список и сигналы приостанавливаются. Состояние каталога видно на главном экране, подробности — в подсказке.
- Идентификатор монеты — тикер базовой валюты в верхнем регистре. У Binance Alpha тикер берётся из официального списка токенов по Alpha ID. В совпадениях возможны коллизии одноимённых активов и пропуски при разных тикерах одной монеты. Сопоставления по адресу контракта и ручных псевдонимов пока нет.
- На каждую монету выбирается один рынок для свечей и сигнала. Сначала выбирается котировка в порядке USDT, USDC, USD, BTC, ETH, затем остальные. При равенстве используется порядок Binance, Bybit, OKX, Bitget, MEXC, KuCoin, Gate, Binance Alpha, затем идентификатор пары. Наличие листинга проверяется по всем активным котировкам.
- Свечи строятся по REST API выбранного рынка. Загружается до 240 минутных свечей, видимые графики обновляются каждые 12 секунд. ЛКМ внутри графика сдвигает время и цену. ЛКМ на шкале меняет только её масштаб. Колесо масштабирует время, кнопка ↦ или двойной щелчок возвращает исходный вид.
- Нажатие и удержание средней кнопки мыши на графике включает линейку с двумя ценами и знаковым процентом. Клавиша F разворачивает график под курсором или активную ячейку. F и Esc возвращают сетку. Оба действия переназначаются в разделе «Графики». Если линейку назначить на ЛКМ, она получает область графика, а шкалы и колесо сохраняют свои действия.

## Фильтры объёма

Все включённые условия минимального объёма должны выполняться одновременно. Выберите 5 мин, 1 ч, 24 ч или период от 1 до 1440 минут. Проверяется оборот выбранного рынка, а не сумма по биржам. USD учитывается напрямую. USDT, USDC, FDUSD, TUSD, USDP и PYUSD считаются по ≈ $1. Для остальных котировок пересчёт не выполняется.

Для 24 ч используются биржевые тикеры. Семь бирж обновляются одним запросом на биржу примерно раз в минуту. Binance Alpha запрашивается по одному рынку за раз. Остальные периоды суммируются по завершённым минутным свечам с минутным запасом на публикацию. Длинные запросы разбиваются на страницы, рынки обходятся с паузами и повторяются независимо от текущего допуска. На широких списках обновление занимает несколько минут, а старые и неполные результаты отображаются как ожидающие. Значения ниже порога и отсутствие данных обрабатываются по-разному. У KuCoin документированные пропуски между подтверждёнными краями окна считаются минутами без сделок. Неподтверждённые края оставляют окно неизвестным.

## Сигналы и сетка

Подписки на публичные WebSocket-сделки охватывают кандидатов после листингов, независимо от сетки. Сигналы и выбор инструмента ограничены итогом общего фильтра. Для MEXC используются подписки Protobuf по 30 инструментов на соединение. Остальные рынки распределяются группами до 100. Соединения переподключаются с увеличивающейся паузой. Статус учитывает подтверждения подписок и количество рынков со сделкой за последние 15 секунд.

«Импульс цены» включён по умолчанию. Пороги по умолчанию — 4% за 15 с, 5% за 1 мин, 12% за 5 мин и 20% за 15 мин. Прежние значения и переключатели сохраняются при обновлении. «Импульс объёма» включается в разделе «Модули». Его стартовые пороги — 100, 400, 2000 и 6000 USD за те же периоды. Каждая строка включается независимо. Дополнительные периоды задаются в секундах до одного часа.

Импульс цены использует две свежие сделки около границ окна. Импульс объёма суммирует цену × количество с дедупликацией по идентификаторам сделок. Суммы агрегируются по секундам с секундным буфером, а после разрыва соединения окно заполняется заново. Сигнал повторно разрешается ниже 75% порога. В каждом модуле действует пауза 30 секунд на инструмент. Готовность объёма в статусе относится к кратчайшему включённому окну. Синхронизация часов Windows, ликвидность, региональная доступность и лимиты бирж влияют на покрытие.

Сигнал открывает график в первой свободной ячейке. Заполненная сетка заменяет самый старый незакреплённый график. При полном закреплении сетка сохраняет текущие графики. Сигнал по уже открытому рынку сохраняет его позицию. Ручной выбор фиксирует график. Кнопка закрепления позволяет менять его состояние. Сетки 2×2 и 3×3 используют общие первые четыре позиции.

## Сборка и обновления

Требуются Windows x64 и .NET 10 SDK для разработки. Готовый EXE включает нужный рантайм.

```powershell
dotnet run --project tests/ThinMarketMonitor.Checks -c Release
dotnet run --project tests/ThinMarketMonitor.Checks -c Release -- --live
dotnet publish src/ThinMarketMonitor -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/publish
```

Пуш тега формата `vMAJOR.MINOR.PATCH` запускает Windows-сборку, автоматические проверки, запуск EXE и публикацию в GitHub Releases. Раздел «О программе» в настройках проверяет последний стабильный релиз этого репозитория. При наличии новой версии кнопка скачивает EXE, сверяет размер и SHA-256 из метаданных GitHub, затем атомарно заменяет файл после выхода. Предыдущая версия сохраняется до подтверждения запуска новой. При сбое запуска выполняется попытка отката. EXE выпускается без подписи Authenticode. Для автоматического обновления используйте папку с правом записи.
